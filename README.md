A CLI logic puzzle game written in Python

---

## 🎮 How to Play

1. You are given a pool of **5 words**.
2. The game secretively picks **4 words** without replacement and puts them in a random order.
3. Your goal is to deduce both the **correct 4 words** and their **exact sequence** within **6 attempts**.

### Feedback Mechanics

- 🟢 **Green**: The word is in the **correct position**.
- 🟡 **Yellow**: The word is in the sequence, but in the **wrong position**.
- ⚪ **Gray**: The word is **not** part of the active 4-word sequence.
